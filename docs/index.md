## นำเสนอโครงการ โดย ฌอน

พี่ฆังต้องการระบบผู้ช่วย AI ที่ **ทำงานอยู่ตลอดเวลา** ไม่ใช่เปิดหน้าต่างแชตแล้วต้องนั่งเฝ้า — และอยากให้สั่งงานได้จากที่ไหนก็ได้ผ่านแชท โดยไม่ต้องเปิด SSH

คำตอบคือ **Kiro Crew** ตัวที่ทำหน้าที่เป็น "หัวหน้าชุด AI" — เปิดบริการเว็บส่วนตัวไว้บนเครื่อง แล้วเชื่อม Discord เข้ามาเป็นช่องทางสั่งงาน

### ทำไมต้องเป็นแบบนี้

เดิมที่ทำงานอยู่ใช้ AI ผ่านเครื่องมือบนเดสก์ท็อป แต่มีข้อจำกัดที่แก้ยาก

| ปัญหาเดิม | ทำไมถึงแก้ไม่ได้ด้วยการเพิ่มแค่เครื่องมือ |
|---|---|
| ต้องนั่งหน้าคอมพิวเตอร์ | ปิดเครื่องแล้วงานหยุด |
| เปิด SSH เข้าเครื่องเสี่ยง | เปิดช่องทางเข้าเครื่องโดยไม่จำเป็น |
| ไม่รู้ว่า AI ทำอะไรไปบ้าง | ไม่มีประวัติและไม่มีจุดอนุมัติ |
| คุยกับ AI หลายตัวยาก | ต้องสลับหน้าต่างเอง |

### สิ่งที่จะได้

- **สั่งงานจาก Discord** — ส่งข้อความใน DM แล้วเริ่มงานได้ จาก Notebook ผ่าน Tailscale
- **อนุมัติในแชท** — เห็นว่า AI จะทำอะไร กดอนุมัติหรือปฏิเสธได้ก่อน
- **AI หลายตัวคุยกันเอง** — คนละตัวทำงานคนละส่วน แล้วส่งผลต่อกัน
- **ย้อนดูย้อนหลังได้** — มีบันทึกว่าอะไรเกิดขึ้น และหยุดงานฉุกเฉินได้ทันที

### ขอบเขตที่ตกลงกันแล้ว

::: danger สถานะจริง ณ3 ต.ค. 2569 — อ่านก่อนทำตามแผน
เอกสารชุดนี้เขียนจากการออกแบบไว้ก่อนติดตั้งจริง ตอนนี้ตรวจพบจุดที่ต่างจากแผน:

- คำสั่งติดตั้งที่ถูกคือ `kiro-cli crew -y` — **ไม่ใช่** `curl -fsSL https://download.kiro.dev/cli.sh | sh` (อันนั้นติดตั้งแค่ kiro-cli)
- ค่าเริ่มต้น approval ของ Crew คือ **`auto`** ไม่ใช่ `interactive` — ถ้าไม่ตั้งเอง งานที่มีผลจะทำได้โดยไม่รออนุมัติ
- Crew มี `kirocrew tailnet up` จัดการ Tailscale เอง — ไม่ต้องเพิ่ม Serve route `:8444` เอง
- **strict sandbox ยังใช้ไม่ได้** เพราะ user namespace ถูกปิด และยังไม่ได้ตั้ง approval/lifecycle ให้ถูก
- ยังไม่มี service, Discord, โทเคน, หรือ Tailscale route ใหม่

รายละเอียดทุกข้ออยู่ที่ [๕. การตรวจสอบ](/verification)
:::

::: tip ตกลงกันเรียบร้อยก่อนเริ่ม
- ติดตั้งทั้งหมดที่ **sv** — เครื่องนี้เป็นแค่ลูกค้ัสที่เปิดแชท
- ใช้ **Discord** เป็นช่องทางหลัก เริ่มจาก DM
- เริ่มจาก **Kiro CLI + OpenCode** ก่อน แล้วค่อยต่อ `agy` และ Copilot ทีหลัง
- โหมดปกติเป็น **interactive** — เราตั้งเอง (ค่าเริ่มต้นของระบบคือ `auto`) · Autopilot เปิดเฉพาะงานที่อนุญาต
:::

เอกสารชุดนี้เขียนให้พี่ฆังอ่านตรวจก่อนเริ่มงานจริง ทุกข้อมูลมาจากการตรวจระบบจริงบน sv ไม่มีการเดา
